# United AI Agent (يونايتد)

"يونايتد" هو عميل ذكي (AI Agent) متعدد المهام، مصمم ليكون مساعداً ذكياً يتفاعل مع المستخدمين باللغة العربية، مع بنية برمجية مرنة تسمح بإضافة مهارات وأدوات جديدة بسهولة.

## المميزات
- **تفاعل طبيعي:** يدعم المحادثات باللغة العربية بأسلوب ذكي ومهني.
- **نظام ذاكرة:** يتذكر سياق المحادثة لتقديم إجابات أكثر دقة.
- **بنية قابلة للتوسع:** مصمم بطريقة تسمح بإضافة أدوات (Tools) برمجية مستقبلاً.

## المتطلبات
- Python 3.11+
- مفتاح API لـ OpenAI (يتم ضبطه عبر المتغيرات البيئية).

## التثبيت والتشغيل
1. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
2. قم بتشغيل العميل:
   ```bash
   python main.py
   ```

## هيكل المشروع
- `core/`: يحتوي على المنطق الأساسي للعميل ونظام الذاكرة.
- `tools/`: (قيد التطوير) سيحتوي على الأدوات الإضافية مثل البحث والعمليات الحسابية.
- `main.py`: ملف التشغيل الرئيسي للتفاعل مع العميل عبر سطر الأوامر.
